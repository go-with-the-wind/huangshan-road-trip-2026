# 2026-11 黄山·宏村·唐模亲子行程页 设计

## 目标
一个可以直接部署到 GitHub Pages 的静态页面 `index.html`，供一家四口（父母、9 岁女儿、7 岁儿子）在 2026-11-25 至 11-28 出行时用手机查看。

## 已确定的约束
- 交通：厦门北 → 黄山北 坐动车，回程 11-28 从黄山北坐动车回厦门。车次未定，页面留占位，不假设具体车次。
- 住宿：11-25、11-26 住宏村（酒店未定，留占位）；11-27 住黄山雲麓北海宾馆（北海景区）。
- 行程：11-25 到宏村；11-26 游宏村；11-27 上黄山，住山上；11-28 下山游唐模，然后返程。
- 带 7 岁、9 岁孩子：上下山都坐索道，不安排长距离陡阶，不进西海大峡谷全程。

## 页面结构
1. 首屏：标题、日期、一句话概括。
2. 行程总览：4 天时间线 + 内置 SVG 路线示意图（无第三方地图依赖）。
3. 每日安排：时间、交通（站点间距离和车程）、看点、餐饮建议、注意事项。
4. 天气：宏村、黄山山顶（北海/光明顶）、唐模分别列出 11-25 至 11-28 的预报。
   - 页面内写入 2026-11-23 查到的预报，并注明查询时间。
   - 打开页面时用 Open-Meteo（免费、无密钥）按坐标拉取最新预报覆盖显示；请求失败时显示内置数据。山顶使用海拔参数。
5. 穿衣建议：按村落和山顶两种环境分层；大人和两个孩子的装备清单；冰雪天防滑。
6. 上黄山路线（重点）：推荐路线、轻松备选、每段步行时间、索道时间与票价、门票及儿童政策、实名预约、行李寄存、日出日落位置与时间、恶劣天气（大风停索道、雾、冰冻）预案。
7. 注意事项与资料来源：所有时间与价格注明来源，标注“以景区官方公告为准”。

## 调研
- 黄山路线、索道、门票以黄山风景区官方信息为主，辅以游记 / 小红书笔记（可检索到的部分），用户来源与官方来源分开标注。
- 调研结果写入 `docs/travel/` 下的 Markdown 文件，与宁德行程的做法一致。

## 不做
- 不接入高德等需要密钥的地图。
- 不做美食专题和小红书点评专栏（未要求）。
